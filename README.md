# Voxel Sandbox (Minecraft Clone)

Clone Minecraft berbasis web. Voxel 3D, kamera FPS, hancur/taruh blok.

## Status
Sedang dikembangkan. Lihat `CHANGELOG.md` untuk progres.

## Cara Menjalankan
```bash
npm install
npm run dev
```
Buka http://localhost:5173

## Milestone 0 (saat ini)
- 1 kubus hijau di tengah scene, kamera diam.
- Overlay FPS di pojok kiri atas, update 1x per detik.

Kontrol
Belum ada kontrol di M0 (WASD/mouse/klik hadir di milestone berikutnya).
